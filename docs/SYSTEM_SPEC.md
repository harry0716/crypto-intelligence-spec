# 系統規格書

## 1. 系統名稱

Crypto Intelligence Daily

## 2. 系統目的

建立一套每日自動執行的加密市場情報系統，專注於 BTC 與 USDT，同時追蹤全球加密市場、穩定幣、ETF、DeFi、RWA、監管、稅務、交易所、資安事件及公開社群熱點。

## 3. 主要使用者

- 系統擁有者
- 加密市場研究者
- 資訊安全與數位經濟研究者
- 需要定期市場情報報告的管理者

## 4. 核心輸出

每日輸出：

- `Crypto_Market_Intelligence_YYYY-MM-DD.html`
- `Crypto_Market_Intelligence_YYYY-MM-DD.pdf`
- JSON metadata
- SQLite 歷史資料
- Gmail 郵件
- GitHub Actions artifact

每 3 日額外輸出：

- 三日深度分析章節
- 三日價格與事件比較
- 領先/落後觀察
- 可驗證假說

## 5. 功能需求

### FR-01 市場資料

系統應追蹤：

- BTC/USD
- BTC/TWD
- USDT/USD
- 24h / 7d 漲跌
- 市值
- 24h 成交量
- BTC dominance
- USDT 脫鉤幅度
- 主要交易所價格差
- 穩定幣供給與資金流（可取得時）
- 資料來源與截點

### FR-02 新聞與政策事件

系統應收集：

- 官方監管機關公告
- 主流財經與加密媒體
- ETF 資金動態
- 交易所事件
- 鏈上資安事件
- 穩定幣事件
- DeFi、RWA、代幣化經濟事件
- 全球規則、稅務與監管變動

### FR-03 Top 10

每條資訊必須包含：

- 標題
- 摘要
- 發生時間
- 來源
- 影響標的
- 利多／利空／中性
- 短期影響
- 中期影響
- 可信度
- 事實／推論／傳聞分類

### FR-04 社群熱點

系統應辨識：

- 敘事升溫
- 異常聲量
- 重複轉載
- 單一來源擴散
- 機器人或協同行為跡象
- 可能操縱訊號

MVP 可先以公開 RSS、Reddit、GitHub、官方公告與公開網頁為主，不強制整合 X API。

### FR-05 報告

報告章節：

1. 今日市場總覽
2. BTC 與 USDT 技術及結構觀察
3. 今日最重要 10 條情報
4. 全球規則與政策變動
5. 社群與資訊熱點
6. 價格與消息面關聯
7. 風險警示
8. 未來 24 至 72 小時觀察清單
9. 三日深度分析（每 3 日）

### FR-06 寄送

- 支援 Gmail
- 支援 dry-run
- 寄送 PDF 附件
- 郵件本文包含摘要
- 失敗時保留 artifact 與 log

### FR-07 歷史資料

系統應保存：

- 每日市場快照
- 每日來源與原始值
- 每日事件
- 分類結果
- 報告 metadata
- 發送結果
- 錯誤與 provider health

### FR-08 即時情報工作台

系統應提供僅供本機使用的 Web GUI，供使用者手動啟動研判：

- 輸入情境標題、個人觀察、預估方向、緊急程度與可驗證來源 URL
- 即時擷取市場快照與公開事件，沿用既有 provider 降級策略
- 使用者輸入一律標示為待驗證觀察或推論，不得因使用者輸入而直接成為事實
- 輸出判斷摘要、事實證據、關聯事件、風險、不確定性與後續驗證指標
- 保存輸入、資料來源、輸出 JSON/HTML、provider health 與產生時間，供日後追溯
- 支援瀏覽近期研判結果
- 不提供自動交易、買賣指令、錢包操作或個人化投資建議

## 6. 非功能需求

### NFR-01 可維護性

- provider adapter
- service layer
- repository pattern
- configuration-driven
- typed models
- unit tests

### NFR-02 可擴充性

新增資料來源時，不得修改核心分析流程，只新增 adapter 與設定。

### NFR-03 可追溯性

每個數字與結論都應能追溯至來源、時間戳與處理流程。

### NFR-04 韌性

單一 provider 失效不得阻止整份報告產生，應降級、標示缺失與降低可信度。

### NFR-05 安全性

- secret 不得進入 repository
- OAuth token 加密保存
- 外部內容視為不可信輸入
- 防止 prompt injection
- 不執行新聞或網頁中的任何指令

### NFR-06 成本控制

- API 可設定每日預算
- LLM 呼叫可快取
- 相同內容不得重複摘要
- 先規則式處理，再使用 LLM

### NFR-07 本機介面安全

- 工作台預設僅綁定 `127.0.0.1`
- 手動輸入具長度與 URL 格式限制，並以 HTML escape 呈現
- 不在 HTTP 錯誤、請求記錄或畫面中透露內部例外與 secrets
- 僅允許讀取工作台產生的命名受限 HTML 產物，不提供任意檔案讀取

## 7. 明確不做

MVP 不包含：

- 自動交易
- 投資建議
- 個人化買賣訊號
- 交易所下單
- 錢包簽名
- 私鑰管理
- 保證獲利模型
